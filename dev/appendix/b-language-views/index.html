    부록 B. 언어 뷰 보안약점 153개와 적용성¶

    이 쪽의 목차
    • B-1. C·C++ 뷰(CWE-658·659) 73개
    • B-2. Java 뷰(CWE-660) 56개
    • B-3. C·C++와 Java 뷰 공통 24개

    이 부록의 역할. 이 부록은 세 뷰의 구성원 가운데 보안약점 점검 목록 44개를 뺀 153개의 적용성 판정 기준표다. 항목별 구현 지침·도구 미지원 시 대안·근거는 각 항목의 규칙별 해설에, 언어별 쪽은 언어별 규칙(C·C++·Java)에 있다.

    읽는 법. 번호와 언어의 대응(658=C, 659=C++, 660=Java)은 MITRE CWE 뷰 정의(CWE-658·659·660)를 따른다. 구성은 언어 뷰별 B-1 C·C++, B-2 Java, B-3 두 계열 공통이고, 표마다 '범주' 칸(MITRE CWE-1400, 색인의 범주)이 있다. 적용성은 이 가이드의 판정 규칙이다: 사용 기술·특성이 전제된 항목은 '조건부'로 두고 조건을 적는다(과제가 그 기술·특성을 쓰지 않으면 비해당으로 판정하고 그 판정과 사유를 부록 G-4에 기록한다).
