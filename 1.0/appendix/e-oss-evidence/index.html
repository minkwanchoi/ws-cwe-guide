    이 부록의 역할. 실제 무기체계 과제는 공개할 수 없어 성격이 가까운 공개 프로젝트(무인기·우주 비행 소프트웨어, RTOS, 칩 제조사 SDK 등)를 참조 프로젝트로 삼았다.

    읽는 법. GitHub 근거는 태그로 고정한 원문을, 벤더 문서·CVE 기록 같은 웹 문서는 조회일을 적은 원문을, 논문은 원문 파일을 글자 그대로 대조했다. 확인일은 항목에 적힌 조회일을 따르고, 따로 적지 않은 항목은 2026. 10. 15.~2026. 10. 16.이다. GitHub 근거의 링크는 같은 태그의 원문이다. 이 사례는 지침이 실제 임베디드 코드에 쓰인 예다. 무기체계 적합성을 입증하지 않는다. 근거 원문의 문장은 저작권을 고려해 싣지 않으며, 공식 링크와 위치로 대조한다. 각 자료의 조건은 출처와 이용 조건에 있다.
