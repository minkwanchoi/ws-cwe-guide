    Java 규칙(CWE-660 뷰)¶

    CWE-660은 MITRE CWE의 언어 뷰로, Java로 작성된 소프트웨어에서 나타나면서 모든 언어에 공통되지는 않는 보안약점을 모은 목록이다(MITRE CWE 5.0 뷰 정의). 이 페이지는 이 뷰의 구성원과 언어와 관계없이 적용하는 「보안약점 점검 목록(44개)」을 한 표에 함께 싣는다.

    CWE-660 구성원 84개 가운데 4개는 보안약점 점검 목록에도 있다. 보안약점 점검 목록에만 있는 40개를 더하면 함께 적용할 범위는 124개다. 표의 'CWE-660' 칸과 '보안약점 점검 목록' 칸으로 어느 쪽에 드는지 본다. 보조 항목 4개(CWE-295·299·611·916)의 정의와 근거는 색인의 보조 항목을 본다.

    '범주'는 MITRE CWE-1400(모든 약점을 정확히 한 묶음에 넣는 MITRE 범주화)을 따른다. 묶음 이름은 이 가이드의 번역이고 영문은 색인의 범주에 있다. '보안약점 점검 목록' 칸의 ✓는 매뉴얼 부록 7의 「보안약점 점검 목록」 44개에 드는 항목이다. 'Java 예시'는 그 CWE의 규칙별 해설에 이 가이드가 새로 쓴 Java 나쁜 예·좋은 예가 있는지다('예시 없음'은 언어 특성상 생기지 않거나 MITRE가 적용 언어를 다른 언어로 한정해 사유를 적은 것). Java 구현 지침은 본문 5.5, 환경 지침은 부록 C의 LJ 지침에 있다. 보안약점 점검 목록만 분류별로 보려면 보안약점 점검 목록 규칙(44개)을 본다.
