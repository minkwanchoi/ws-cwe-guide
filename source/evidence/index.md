# 검증 방법

이 가이드의 근거를 어떻게 확인했는지 요약한다. 대조에 쓴 원문 발췌와 작업 기록은 제3자 저작물의 저작권을 고려해 공개하지 않는다. 독자는 부록 E와 Excel '오픈소스근거' 시트의 공식 링크와 위치로 원문을 직접 대조할 수 있다. GitHub 근거는 태그나 커밋으로 고정했고, 판 번호가 없는 웹 문서는 확인일 기준이므로 그 뒤 원문이 바뀌었을 수 있다.

- **원문 대조**: 주장을 출처 단위로 나누고, 태그로 고정한 원문이나 조회일을 적은 공식 문서를 받아 근거가 되는 문장이 원문에 있는지 기계로 대조했다.
- **독립 재검증**: 조사자가 '확인'으로 판정한 근거 가운데 20~25%를 표본으로 뽑아 원문 문맥과 다시 대조했다. 공식 원문이 아닌 사본은 근거로 쓰지 않는다.
- **예시 코드 검증**: 조합마다 컴파일하고, 나쁜 예는 분석기·새니타이저·실행 결과로 드러나는지, 좋은 예는 드러나지 않는지 확인했다. MITRE 원문 예시와의 유사도도 기계로 점검했다.
- **표기 점검**: 맞춤법·띄어쓰기·번역투를 점검하고 용어집으로 표기를 통일했다.
- **문장 유사도 점검**: 본문을 공개된 한글 원문과 기계로 대조해 원문을 옮긴 부분이 없는지 확인했다(2026. 11. 1.). 글자 정보가 없는 PDF와 영문 원문의 번역은 기계로 대조하지 못했다.
