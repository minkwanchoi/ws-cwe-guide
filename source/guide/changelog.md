# 변경 이력

판마다 독자에게 달라지는 내용을 적는다. 지금 보는 판은 쪽 머리글의 제목 옆과 꼬리말에 있다.

**판 번호의 뜻.** 판 번호는 `큰 번호.중간 번호.작은 번호`로 쓴다.

| 올리는 자리 | 언제 | 독자가 할 일 |
|---|---|---|
| 큰 번호(`2.0.0`) | 기준 문서가 바뀌어 지침 체계가 달라질 때(매뉴얼 새 판, CWE 큰 개정), 지침 ID 체계가 바뀔 때 | 적용 중인 지침과 판정을 다시 확인한다. |
| 중간 번호(`1.1.0`) | 지침·환경·특성을 더하거나 근거를 크게 보강하거나 장·절 구조를 바꿀 때 | 바뀐 지침이 과제에 해당하는지 확인한다. |
| 작은 번호(`1.0.1`) | 오탈자, 문장 다듬기, 깨진 링크 교체, 근거 판정 정정 | 근거 판정 정정이 있으면 해당 지침을 확인한다. |

**적는 내용.** 판마다 바뀐 지침 ID와 CWE 번호, 기준 자료의 변화, 정정한 내용을 적는다.
